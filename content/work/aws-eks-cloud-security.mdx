## Overview

A graduate course project for CS581 (Cloud Security) at SFBU, built with a team of three. This was not a production deployment — it did not run continuously in front of real traffic — but a scoped exercise in designing and provisioning secure cloud network and cluster infrastructure.

## What it covers

- VPC design, including subnetting and routing.
- An AWS EKS cluster provisioned with both `eksctl` and Terraform.
- Security groups and network ACLs at the VPC layer.
- Kubernetes network policies at the cluster layer.
